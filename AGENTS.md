# WCAG plugin

This repository is an agent plugin, not an application. It ships eight skills for auditing,
remediating, and rebuilding against WCAG 2.2, plus the scripts they call. It targets both
coding agents and desktop agents working on someone's documents.

## Layout

- `skills/` holds the skills. `wcag/SKILL.md` is the router and the shared contract; the
  rest cover web, PDF, documents, mobile, remediation, recreation, and reporting.
- `references/` holds material used by more than one skill: the full WCAG 2.2 criteria
  catalogue and its generated index, conformance rules, severity, legal mapping, media
  guidance, the desktop agent capability envelope, and the built-in accessibility
  checkers.
- `scripts/` holds the executable checks. They are Python 3, standard library only except
  where noted in each file's docstring.
- `commands/` holds the slash commands.
- `tests/fixtures/office/` holds the Office fixtures, generated by
  `tests/fixtures/build_office_fixtures.py`. Regenerate rather than editing them by hand.
- `.claude-plugin/`, `.cursor-plugin/`, `.codex-plugin/` and `.agents/` hold the manifests
  for each host.

## Working on this repository

Run `scripts/selfcheck.py` before committing. It validates the manifests, checks every
skill has the frontmatter its host requires, verifies that internal links resolve, and
confirms the criteria table in `scripts/report.py` matches the W3C numbering.

The success criteria numbering, titles, and levels were generated from the W3C WCAG 2.2
guidelines source. If you change them, regenerate rather than editing by hand, and keep the
counts at 31 Level A, 24 Level AA, and 31 Level AAA, with 4.1.1 removed. `references/sc-index.md`
is generated from that same table by `scripts/build_sc_index.py`, so run it after any change
and commit the result.

Every finding carries an `agent_fix` value saying who can close it. The five allowed values
are defined once, in `assets/finding-schema.json`, explained in `references/desktop-agents.md`,
and rendered by `scripts/report.py`. `selfcheck.py` fails if those three disagree.

Documentation in this repository follows the anti-slop rules at
https://github.com/miqdadbadjuber/anti-slop. In practice: no em dashes, no buzzword
vocabulary, name the actor in each sentence, no invented numbers or claims, and no
inline-header bullet lists outside the documented conventions.
